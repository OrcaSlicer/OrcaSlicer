# 腾讯混元 3D 接入

本次在 Tripo 同一主窗口流程加入“腾讯混元3D”，公共 provider 为 `hunyuan`。供应商只影响生成和任务查询，不改变设计图确认、预览、历史和导入步骤。旧记录默认仍属于 Tripo。

## API 选项

依据 [腾讯官方 HY-3D 调用指南（2026-09-08）](https://cloud.tencent.com/document/product/1823/137181)：

| 项目 | 本次选择 |
| --- | --- |
| 接口 | TokenHub `https://tokenhub.tencentmaas.com/v1/api/3d/submit`、`/query` |
| 鉴权 | Bearer，密钥只读环境变量 `HY3D_API` |
| 模型 | 固定 `hy-3d-3.1`，避免恢复时随环境改成另一个模型 |
| 生成模式 | `generate_type=Normal`，带纹理几何；2026-09-14 真实错误响应确认枚举大小写敏感 |
| 面数 | 默认 100 万，可选 30 万；API 范围 3000–1500000，本界面沿用现有常用档位 |
| 材质 | `enable_pbr=false`，保留基础纹理；本次不提供 Tripo 的高清/8K 参数 |
| 输出 | GLB 默认，OBJ 可选；不传 `result_format`，使用服务返回的两种结果，无额外转换提交 |
| 图生模型 | 确认图转 `image_base64`；不把提示词和图片同时提交 |
| 纯文本后备 | `prompt`；不超过 1024 字符 |
| 多视图 | 主图加 left/back/right；每视角一张，输入体积/尺寸在提交前检查 |

Windows 优先读取进程环境；缺值时仅查询当前用户环境的 `HY3D_API`，不导入其他环境变量、不写凭据配置。这里使用 TokenHub API Key；腾讯云 SecretId/SecretKey 的 TC3 接口不是本次实现。旧平台 API Key 能否用于 TokenHub 以实际鉴权结果为准。

## 任务和边界

每次确认最多创建一次模型任务。提交前保存意图，响应不明确时不自动重提、不切换供应商。成功拿到的任务 ID 在恢复时原样查询；停止只结束本地等待，不声称取消远端计费。任务 ID 官方有效期为 24 小时，结果应在完成后下载进软件历史资产。

设计创建时保存服务商、面数、几何、纹理和格式；已确认设计图上的这些选项变更通过本机 `generation-options` 接口立即保存，不提交任务。文字 JSON 和图片 multipart 入口均接收完整选项；旧客户端缺字段时保留原默认值。保存期间控件锁定，重启后恢复已保存的选项；已提交任务不允许借此更换服务商。未确认的保存错误会提示重新打开设计核对。

本次不接入混元重新上色、极速版、低模、PBR 开关或其它收费后处理；混元历史模型的 Tripo 重新上色操作会被拒绝。模型导入继续使用 Orca 原生交接，不自动切片或改预设。
