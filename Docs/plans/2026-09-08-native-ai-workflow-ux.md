# 原生 AI 样板流程实施计划

**Goal:** 最小改造当前主窗口的生成、直接编辑、打印检查与原生切片衔接。

**Architecture:** 复用 ModelGenerationPanel、SmartSlicingPanel、当前 Orca Model、适配器和原生撤销。增加有界模型准备操作，保持 provider、格式、预设与发布流程不变。

**Tech Stack:** 当前分支 C++17、wxWidgets、OpenGL、CMake、Catch2 与固定离线样例。

依据：[初始问题与样板方案](../audits/2026-09-08-native-ai-workflow-ux.md)。用户已授权先审查、再最小实施；保留现有工作树，不另开永久任务或要求重复确认。

1. 为 `GUI/AI/Orca` 增加最小模型准备 helper：验证选中单对象/单实例、明确 mm 单位、同比例设置整体高度、可选圆柱底座、原始几何和颜色保留；先计算和验证，后提交。实际 workspace 变更由专用原生准备面板使用快照与更新入口。
2. 在 `SmartSlicingPanel` 增加简短准备控件及当前对象/设备说明；复用当前 revision timer，编辑或设备改变后旧检查失效；失败就地提示，阻止忙时编辑和重复提交。保留原生手动切片入口。
3. 在生成页澄清图像处理参考尺寸与实际模型尺寸，补齐成功导入后的返回继续入口，保留已有结果与历史。不把大小或底座修改转换为再次生成。
4. 通过主窗口既有主题/DPI 回调和 AI 面板可见刷新路径同步外观；复用当前 GUI_App 颜色和字体，区分 UI 背景与真实耗材色卡，模型 OpenGL 背景随主题更新。只修改 AI 界面和必要组合入口。
5. 在现有测试位置添加行为用例与必要固定样例，覆盖准确尺寸、底座接触、非法输入不修改、已有颜色/版本保留、变更失效与恢复；运行相关现有测试、当前增量构建及集成检查。保留全部检查发现。
6. 更新修改前后对比和测试证据。实际 GUI 无法运行时明确未验证项；仅把已验证的接口与回归方法沉淀到工程导航及项目 Skill，不把未走查视觉假设写成有效规范。

验证命令沿用 [当前已验证工具链](2026-09-08-ai-journey-interaction-fixes.md)：单套增量构建 `OrcaSlicer_app_gui slic3rutils_tests`，相关测试在 `resources` 工作目录执行；`python scripts/verify_ai_integration.py --json`。不运行付费 API、旧分支比较或此前被拒绝的隔离启动。

## 执行结果

1–4 的有界代码改造已完成，并补齐正式切片完成/失败后的版本监测、未知版本提示和快速重选对象校验。最终 Release 构建通过；89 个相关 C++ 用例 / 851 个断言、41 项 Python 测试通过。集成检查保留 4 项既有发现，无新增预算问题。

第 6 项的审查报告、工程导航和现有项目 Skill 已更新。第 5 项的实际主窗口流程、返回/撤销焦点、主题/DPI 和普通 Orca GUI 回归尚未验收：此前隔离实例启动被工具策略拒绝，本轮未换入口重试。逐项证据、未实现能力与实机清单见 [审查报告](../audits/2026-09-08-native-ai-workflow-ux.md)。
