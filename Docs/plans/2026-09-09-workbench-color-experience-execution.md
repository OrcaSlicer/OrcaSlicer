# 五项体验优化执行计划

状态：本轮完成。用户明确授权分析、开源调研、实现、验证及修正，中间自主推进。协同分支及飞书另由其他会话处理，本计划不操作这些内容。

## 目标

让默认图片展示干净、六色预览可信、编辑统一在3D美颜工作台、重新设计路径清晰，并把生成侧试色与原生导入配色衔接起来。保留原件、版本恢复、普通Orca工作方式；需要的分析只提供建议，不能成为额外流程门槛。

## 顺序与验收

1. 图片背景：移除“查看原始AI图”切换和技术警告；透明背景用纯色展示，历史棋盘格默认清理，展示处理不得混入供应商输入／历史原件。验证透明和已烘焙棋盘格两类输入。
2. 六色：核对GPU基础色与光照；默认准确显示最多六个分色色块，立体光照明确区分，保护色可保留；检查计数、恢复原色、版本切换和导入传递。
3. 入口：移除高级工具和重复重新设计区，把有用编辑收进工作台；重新开始提供直接开始／先看建议／取消，分析失败仍可继续，不自动收费分析。
4. 美颜：研究开源保形平滑、局部权重、轻量交互和许可证；优化百万面模型局部处理及边界过渡，收敛参数，保证对比、取消、保存、回退仍正确。
5. 导入配色：梳理原生真实路径、目标色聚类、实体耗材、虚拟叠色和应用时机；研究现有开源方案，选择能复用现有引擎的改进，避免生成预览与导入重复无关联减色。六个基础目标色不等于六个物理槽，屏幕色不冒充CMYK实物效果。
6. 定向离线测试、Windows构建、同一历史人物模型主窗口验收。记录每项真实证据、剩余限制及开源参考。不得将编译／单测称为打印效果验收。

## 已知事实

- 当前 shader 先按最多6个目标色选色，再乘连续光照；因此屏幕出现超过6个RGB值并不表示目标色表超过6个。
- 工作树包含前轮美颜、原生导入、背景和试色等未提交成果，原样保留；不得为本轮重置或清理。
- 项目当前已有OpenGL预览、区域选择、Taubin式本地柔化及原生纹理配色能力；优先完善现有实现，不引入庞大编辑器框架。

## 工作分配

主代理：图片展示、页面入口、重新开始、工作台衔接、最终构建与主窗口验证。独立内部检查：几何引擎性能与柔和边界；六色着色器／控制；原生配色流程与界面。各自文件范围隔离，共享契约和组合入口由主代理协调。
