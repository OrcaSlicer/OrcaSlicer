# 不限色生成与生成后三维处理

2026-09-09，用户已明确：第 1、2 项由当前任务实现并实际验证 UX；第 3 项仅交接智能切片同事。工作树为 `codex/continue`，保留此前全部修改。

## 实施范围

1. 去掉生成页打印限色入口；创建、预处理、重试、新生成和模型输出不再注入耗材 palette，不运行生成前减色。历史原件仍可查看。用户自选单色雕塑等风格属于创作意图，不能由耗材数量强制选择。
2. 生成页增加本地三维表面平滑与保守网格清理。计算在后台，结果先预览；同视角切换处理前／后，接受后形成派生版本，支持返回上个版本。保留 OBJ 颜色和材质关联，限制过量变形，不冒充人脸语义重塑或全自动补洞。
3. 智能切片 AI 原生配色仅保留独立交接文档，不在本轮实施。

## 验证

- 固定彩色图，mock 图片／3D 服务，检查实际请求和像素，验证设备 palette 不改变生成路径；覆盖旧字段、预处理失败、恢复和重复确认。
- 几何测试验证噪声降低、边界／锐边保护、变形上限、退化／重复面清理、原件及 UV／颜色保留、非法文件和取消。
- 编译后用当前仓库可执行程序和独立测试数据实际操作主窗口：输入、生成、处理预览、接受、撤回、历史恢复、导入、页面往返和普通 Orca 操作；记录准确产物和证据。真实付费服务与真实打印效果不由 mock 证明。
- 运行受影响回归及 `scripts/verify_ai_integration.py --json`，报告所有遗留和新增发现。
