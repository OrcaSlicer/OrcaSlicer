# R1-g 衣料保护：用户测试说明

状态：2026-09-16，已修改／构建／代码测试，待用户验收。分支 `codex/feat/local-semantic-coloring`。

## 启动与重新配色

双击 [R1-g-color-test.cmd](../../../../R1-g-color-test.cmd)。程序使用独立测试设置和四个真实历史模型的副本；修改和保存留在此测试目录。启动终端在程序退出后结束，请保留它运行。

1. 打开“3D 生成 → 历史资产”，选择方飞、刘亦菲、双人或动物的原始模型。
2. 选择色卡“人物基础·年轻向六色”，保持“人像区域优化”开启，等待处理结束。色卡按顺序为 `#F7E2DA,#282629,#F6F7F9,#EA9A92,#668CB6,#958B86`。
3. 切换原色与试色，放大检查下表区域，同时旋转查看侧面与背面。准备页启动时的两个旧对象只用于既有工程／耗材设置，应从历史重新计算原始模型。
4. 可局部改色、返回上个版本／重做，再导入准备页、另存新 3MF 并重开。把异常位置和操作告诉 Codex，即可登记本轮反馈。

## 当前限制

此入口使用仅开放既有历史的本机测试服务，禁止新生成；为绕过已登记的离线历史可用性缺陷，测试 health 暂时声明可用。因此本入口用于 R1 配色测试，不能验收正式无凭据历史功能。

本版本仍含原官方 MediaPipe DLL；关闭统计的 R6 源码运行库尚未构建成功，不能称为配色识别完全无外连的最终版。所有视觉和流程结论由用户测试后追加，不预填通过。
