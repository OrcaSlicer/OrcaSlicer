# 六色耗材包与导入体验优化

用户已授权按原生导入实测结论实施，并提供年轻向六色包。本轮按以下顺序实现与验证：

1. 接入六色色卡：提供准备页与美颜入口、选择/应用/保存当前色卡，按实体槽位应用，保留已有打印参数和涂色区域。应用是明确的工程级操作，不伪装成设备已经装料。
2. 配色闭环：美颜支持预制包快速试色；沿用保护关键色的目标色板；原生匹配显示耗材差异，换耗材立即显示实际耗材视图。
3. 局部操作复用已有工作台选区、局部改色和去杂色；原生全局颜色组修改显示影响范围说明，避免把全局替换当成局部编辑。
4. 修复原生叠色菜单与取消状态；改善重复导入意图、避免新增副本重叠；减少不必要的重复计算。
5. 定向离线测试、集成检查、Release 构建；用已有 190 万面模型验证六色包应用、试色、原生匹配、准备页、切换及取消。保存工程与截图，说明色卡缺少绿色和实物色准未验收的边界。

不执行收费生成、远程推送或联系同事。新色卡的 CMYK 数值仅保留为用户提供的参考，不参与未经标定的 FDM 叠色计算。

本轮实现、Release 构建和定向测试已完成；真实 GUI 完成色卡切换、六色原生导入、3MF 恢复、更新原对象、撤销和取消验收。详细结果和未覆盖边界见 `Docs/audits/2026-09-10-color-pack-implementation.md`。
