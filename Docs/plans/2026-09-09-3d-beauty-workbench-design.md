# 3D 美颜工作台与检查收敛设计

状态：2026-09-09 设计后已获用户批准实施首版；当前实现、取舍及验证见 [工作台验收记录](../audits/2026-09-09-3d-beauty-workbench.md)。以下代码现状为设计时依据。沿用主窗口内承载、原件保留、检查仅提示、最多六色试色与原生配色分工。

## 当前问题与代码依据

- 截图中调参区与模型上下分离，操作时难以持续观察效果；两块“尚未检查”重复，存在无文字折叠入口。
- `src/slic3r/GUI/ModelGenerationPanel.cpp` 的 `refresh_model_quality_card()` 将同一状态和摘要写入 quality 和 decision 两块区域；未检查并不等于模型有问题。
- `src/slic3r/GUI/AI/ModelGeneration/ModelGenerationFinishingView.cpp` 已有预设、强度、处理前后比较、接受新版本、回退和取消，可复用，但当前仍需点击预览完成整份处理。
- `src/slic3r/GUI/AI/Model/ModelFinishing.hpp` 目前仅接受全局平滑、网格修复和强度参数，没有区域权重或人像语义识别。实现保护边界与锐边、限制位移、保留原颜色；不提供脸部磨皮、瘦脸或补洞。
- `ModelPreview3D.hpp` 已有点击区域选择与选区历史，可以作为局部修整入口；局部几何算法和柔边权重仍需补齐，不能将同色组直接称作脸部或衣服识别。
- `tools/ai/printable_model_quality.py` 含局部厚度采样等启发式分析。其结果不能替代当前尺寸、方向、材料和切片条件下的实际判断。

## 推荐工作台

点击“3D 美颜”在 Orca 主窗口内进入专注编辑布局，保留作品与版本上下文。

| 位置 | 内容与职责 |
| --- | --- |
| 中央约三分之二 | 常驻大模型；旋转、缩放、正面／侧面；原色／灰模观察；按住查看处理前 |
| 左侧窄工具栏 | 美颜、局部修整、颜色、修复；每次只展开当前工具 |
| 右侧参数栏 | 当前工具的少量参数、选区和保护范围；可收起原图／设计图参考 |
| 顶部 | 返回作品、撤销／重做、前后对比、保存新版本、进入准备页 |
| 底部 | 简短操作记录与可展开问题提示；不堆放完整质量报告 |

默认纯色背景。灰模与灯光用于观察凹凸，必须与真实几何修整区分。前后比较保留同一视角、缩放和光照；第一版先做按住对比，后续再考虑双视图或分割线。

## 核心能力和顺序

1. **第一版：可控的局部表面修整。** 先保留轻柔／均衡／加强预设，默认轻柔；增加明确选区后的局部柔化，柔边过渡，保护未选区域。首版可用现有点选区域加减选择，笔刷和套索逐步补齐。不得以颜色相近替代空间连通与几何范围判断。
2. **同屏颜色。** 整合已有 1–6 色、保留目标色、原色对照与局部改色入口。试色必须标明未写入工程；正式耗材映射、应用撤销与 CMYK 仍遵循原生配色交接。几何修整后需确认颜色／UV 保持有效。
3. **真正的人像美颜。** 后续增加脸部／头发／衣服的候选分区，允许手动纠正；再做肤色均匀、局部纹理去噪、脸部小凹凸修整。几何变化与表面颜色变化分别控制。瘦脸、五官比例、补全缺失结构需要可靠的三维定位与多视角验证，先不放进一键默认效果。

典型操作：打开模型 → 点选需要柔化的脸颊区域 → 调整强度 → 同视角按住对比并转到侧面 → 保存新版本。眼唇鼻翼等未选区域保持保护，不能声称现阶段自动识别五官。

## 响应速度与状态

- 颜色预览沿用 GPU 更新；几何编辑复用已解析模型与邻接关系，避免每次拖动完整读写 OBJ。
- 拖动时先更新轻量预览，松手后后台精算；首次缓存未就绪时明确显示计算状态。仅采用最新请求结果，支持取消。
- 轻量代理如无法保持选区、UV 和原模型的可靠映射，则不采用简化网格回写。可先采用原拓扑局部计算与事件节流。
- 保存新版本才写出完整产物。撤销／重做记录编辑步骤，原件不覆盖；待计算与待保存状态清楚可见。
- 设计目标为选区及颜色反馈约 100 ms 内可见、几何粗预览约 300 ms 内起效；这些是待验证目标，不是现有性能承诺。用当前 190.7 万面样例实测。

## 检查功能的取舍

| 当前内容 | 推荐处理 |
| --- | --- |
| 重复“尚未检查”卡片、检查任务入口、空白折叠栏 | 删除重复展示和必经步骤；未运行保持中性，不标成通过 |
| 文件可解析性、无效面等基础信息 | 加载时复用已有分析；后台仅计算轻量项目，结果按模型版本缓存 |
| 可解释的网格问题 | 收为“模型提示”；展示问题位置和修复预览动作，用户可忽略继续 |
| 深度厚度采样、悬垂、接地和支撑 | 放到打印准备按尺寸、方向和设备条件按需执行；避免每次编辑全量扫描 |
| AI 对照原图／相似度复核 | 收进可选高级工具；显式调用，不自动运行，不作为质量通行证 |

不自动执行可能改变造型的补洞、删部件或重塑。修复输出新版本并可对比。质量建议不拦截下一步；文件不存在或无法解析时解释具体故障，不能伪造可导入结果。工程或几何变化后使相关报告失效，纯展示颜色／镜头变化不应触发结构扫描。

## 验收与价值

优先验证：模型与参数同时可见；局部修整不影响未选区域；转到侧面没有明显变形；对比镜头一致；取消与撤销可靠；保存及导入正确版本且无隐式切片；颜色试色边界清晰；检查没有重复卡片或下一步门槛；关闭 AI 后普通 Orca 仍可用。

价值用获得可接受版本所需时间、操作次数、保存／撤销选择及实际打印后反馈衡量。不要以“美颜分数”或检查通过率代替用户对相似度与实物效果的判断。
