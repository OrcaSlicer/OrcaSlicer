# 3D 美颜工作台实现与验收

基于 `codex/continue` 的当前工作树，保留本轮之前的修改。用户批准实施 [工作台设计](../plans/2026-09-09-3d-beauty-workbench-design.md)。仅本地构建、离线模型处理及实际主窗口验收；未调用收费生成或 AI 视觉服务。

## 已实现

- 主窗口“3D 美颜工作台”切换：收起生成表单和图片对照，模型与右侧可滚动工具同屏；返回作品恢复原流程。整体美颜、局部修整、颜色预览、网格修复使用同一模型上下文。
- 局部修整：点选添加／擦除连续局部区域，范围可调，选区可撤销／清空。源 OBJ 三角面索引传递给引擎；空选区不执行整体柔化。未选面涉及的顶点及选区边界固定，局部模式禁止整体网格清理。
- 表面柔化默认轻柔；滑块松手才发起后台处理，提供显式预览和取消。当前仍然进行精确 OBJ 处理，不宣称已实现 300 ms 几何粗预览或三维人脸识别。
- 灰模仅改变观察显示；右键拖动平移，左键拖动旋转，滚轮缩放。按住模型上方按钮看处理前，侧栏也支持切换对比；镜头、平移和缩放保留。
- 接受后生成独立版本，支持回到上一个版本及重做该保存版本。版本在模型库保留；这是一层保存版本撤销／重做，选区另有历史，不宣称任意长度编辑栈。
- 重复检查状态卡片去重，默认隐藏高级区域，普通文本按钮展开；未运行分析保持中性提示，质量建议不阻止导入。基础 OBJ 可解析性仍必需；深度厚度／悬垂和可选 AI 复核仍在高级工具中，提示结合准备页条件判断，并未新建第二套准备页分析。
- 为首次局部选择增加后台 CPU 初始化和等待提示，仅在 GUI 线程采用结果与绘制；至多一个准备任务，换模型使旧结果失效。延迟点选保存模型空间射线，避免等待期间旋转后选错位置。
- 美颜前后缓存只保留紧凑模型数组和预览，不保留选区邻接／BVH，避免首次局部对比重新解析原始大文件。

## 实际能力边界

没有自动五官定位、瘦脸／大眼、纹理磨皮、自动补洞或实际 CMYK 叠色。六色仅试色，正式导入仍使用真实保存模型颜色，与原生配色交接一致。局部边界当前固定，没有额外羽化参数；需要由实际模型多视角与打印样件确认美观程度，屏幕与单测不能证明打印色准或制造质量。
