# 6 色外观快速预览试验

## 用户范围与分工

用户希望先在现有模型上体验一键减色、快速预览，目前最多 6 色，并使用 CMYK 空间／层次叠色。具体耗材色号尚未提供。本轮只实现生成页的可逆外观对照，不将试验色板当作当前设备的打印方案。

已阅读 `Docs/plans/2026-09-09-ai-native-color-matching-handoff.md`。文档的职责仍适用，但原生导入实际入口是 `Plater::priv::run_textured_mesh_import_dialog` → `TextureImportDialog`。正式耗材匹配、区域保护、CMYK 配方、工程涂色、切片和撤销继续在原生匹配模块完成。本轮没有修改 `Plater`、`TextureImportDialog`、`TextureToColor`、导入契约、颜色意图或 Sidecar；尚未核实同事的未提交改动，也没有向同事发送消息。

## 实现

- `ModelPreviewPalette.hpp`：CPU 后台准备时，对顶点颜色按相邻三角面积累计 32×32×32 RGB 直方图，使用最多 20 轮面积加权 Oklab 聚类，最多 6 个目标色。首个种子取权重最大项，后续种子兼顾色差与权重。计算结果保存在对应模型的预览缓存中。
- `ModelPreview3D.hpp`：模型下方显示自动色板和“一键预览 6 色／查看原色”。只切换 GPU uniform，不重读 OBJ、不上传新几何、不写模型文件。更换模型及处理前后版本时关闭试色，使用新版本各自的色板；普通页面往返保留当前视图。
- `ModelColorPreviewShader.hpp`：对未加光照的插值颜色映射到最多 6 个代表色，再应用原有照明。原色路径仍输出原有着色结果，局部选择覆盖层关闭减色。六个基色在照明下仍可有明暗变化，不代表像素 RGB 总数只有六种。
- 显示层不写入历史模型、原生耗材或 CMYK 配方。导入仍使用原色文件，界面明确提示。保存并交接打印版本不属于此试验，避免先后经过两套不一致的减色算法。

Oklab 转换依据[作者公开实现](https://bottosson.github.io/posts/oklab/)。这里用于快速外观近似，不替代 Orca 原生 CIEDE2000 匹配或材料标定。第一版实看发现灰阶占用多个色板位置、深绿衣服被合并；第二版在聚类及着色器中统一将 L 分量的距离缩放到 0.35，优先保留色彩差别。这是本次外观试验的权重选择，不是通用打印色差公式。

## 限制与后续评判

没有人脸语义分区、关键颜色锁定、小色块连通清理、CMYK 叠色模拟或实际耗材标定。全局六色可能牺牲嘴唇、瞳孔和肤色层次；不可把源图上的黑色直接解释为最终应使用黑色耗材。此试验主要用于判断速度、全局减色外观及进一步区域保护的必要性。

源模型 953,446 顶点、1,906,896 三角面、39,863 个 RGB8 色值；预览之前的统计见 `.tmp/ux-performance-20260909/color-distribution.json`。源文件和已接受美颜文件保持不变。实际打印的换色次数、时间、浪费量及 CMYK 色准尚未验证。

## 验证记录

首版 Release 构建通过；独立实际主窗口加载了原模型，CPU 准备日志为 1,383 ms，界面加载 1.48 秒；GPU shader 日志 `gl_error=0`。原色／六色均显示成功，但绿色合并的问题促成上述第二版修正。测量来自本地已有文件，未调用生成服务。

定向 C++ 测试首轮与最终修正版均通过：4 用例、70 断言，覆盖最多六色、空输入、单色、面积加权与重细分无关、结果确定性及色彩转换。最终测试日志为 `.tmp/ux-performance-20260909/six-color-tests-v2.log`，随机种子 2019000444。最终 Release 应用与测试目标构建通过，记录在 `build-six-color-trial-v2.log`；定向 `git diff --check` 通过。

集成检查仍报告已知四项：两处模拟凭据字面量（`release/test_verify_package_contents.py:39`、`tools/ai/test_diagnostic_failure_flow.py:106`），以及缺失历史 `codex/model-generation`、`codex/smart-slicing` 引用。检查未被削弱，未重试被阻止的旧工作区比较。

最终修正版在独立的实际 Orca 主窗口体验通过以下行为：原模型首次加载界面显示 1.57 秒（CPU 准备 1,474 ms）；原色／六色切换记录 14、13、13 ms。这是按钮事件到帧提交的耗时，不是屏幕发光延迟或持续帧率。切换不重读几何，六色状态下缩放、旋转可用；切回原色保持相机视角；历史页往返保留试色与视角；切换到已接受的美颜版本恢复原色并采用该模型自己的色板，美颜版加载显示 1.73 秒。重新加载原模型命中预览缓存，恢复原色；最后已重新开启六色试验供用户对照。

外观结论：第二版权重调整仍未充分保护深绿色衣服和嘴唇，自动色板仍偏向灰阶与肤色。快速可逆试色已实现，但六色外观质量尚不能作为最终打印配色验收；下一步需要关键颜色／区域保护，并对接实际耗材。没有实现或宣称验证 CMYK 叠色效果。
