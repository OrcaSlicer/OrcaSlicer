# 2026-09-14 内部测试版修改说明

本版面向 Windows 团队内部测试，源码分支为 `codex/team/model-generation`，PR 目标为 `codex/team/integration`。包的精确提交、构建信息和文件哈希以随包清单为准。

## 主要修改

- 接入腾讯混元 3D：主窗口选择服务商、生成参数和格式，保存设计设置，生成后下载模型并保存在历史中。
- 修复混元 `GenerateType` 枚举大小写，使用服务端接受的 `Normal`；保留脱敏错误详情，明确拒绝且无远端任务的失败可复用设计再次确认，模糊结果不自动重提。
- GLB 本地修整保留贴图，保留原件及版本记录；完善颜色导入设置，支持沿用试色或从原色重新配色。
- 优化小面积高彩度细节的色板保留；分开实体耗材数量与虚拟混色配方限制，修正中性灰混色显示。
- 精确合并闭合网格的颜色/UV 接缝，保持面顺序、几何及逐面涂色；通用修复在副本完成后提交，取消时保留原模型。
- 同步远端 PR 审查修复，包括模型导入缓存识别及颜色转换相关回归。最终同步与检查结果记录于 PR 和内部包清单。

## 已有验证

混元单次真实主窗口生成成功，生成及下载处理约 5 分 26 秒；彩色预览、旋转、历史重新打开、重启恢复原图/设计/模型均通过。恢复操作未新增付费请求。该证据对应同步前冻结快照，最终包另做构建和相关回归。

此前旧婚照模型已完成配色、接缝修复、撤销/重做、四实体耗材导入、切片及工程恢复检查。该切片证据不等于新混元模型已经切片。

## 已知问题与测试重点

- 混元模型首次打开及恢复时默认偏侧面，需手动旋转查看正面。
- 新混元模型存在局部薄壁、悬垂和细小色块提示，尚未切片或实物打印；人脸与照片存在差异。
- 风格推荐辅助请求曾返回 401，正式设计生成成功；辅助接口仍需排查。
- 通用网格修复的底层计算取消响应可能较慢；单次生成成功不代表长期服务稳定性。
- 内部包不包含服务商密钥、个人测试配置、照片或生成资产；服务使用测试者自己的配置。未实施公开发布、自动合入或打印机发送。
