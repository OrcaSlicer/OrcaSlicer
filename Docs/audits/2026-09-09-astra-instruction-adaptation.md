## 已完成的修改

- `AGENTS.md` 不再要求每次小改动通读四份资料；按接手、模块、产品、集成变化分别路由。GUI 验证根据受影响行为选择，完整产品验收仍需完整旅程证据。
- `CONTINUATION.md` 中首次评估流程标明为建仓参考；评估文档缺失不会阻塞已授权开发，未把缺失文档写成已完成。
- `brainstorming` 删除全创意工作强制触发、固定选项/字数、逐段确认与自动提交流程。
- `writing-plans`、`executing-plans` 区分只规划与要求实施，删除固定三项停顿、机械 TDD 步骤、额外任务和不可用技能依赖。
- `code` 从只给指导改为完成已授权实施；同步修正 execution、verification、state、criteria 引用，避免入口变短后旧审批要求又被加载。原 `Code` 名称规范为 `code`，目录不变。
- `planning-with-files-zh` 改为按任务需要记录，移除技能内自动反复注入/完成检查 hooks 和固定操作次数规则，修正相关模板。保留外部内容不作为指令和完整性异常必须报告的要求。未更改宿主审批或安全规则；未宣称旧 hooks 在当前 Codex 中实际运行过。
- `graphify` 改为关系分析和语料探索触发，入口只路由所需参考。原构建细节移至 `references/build-pipeline.md`，帮助移至 `references/usage.md`；修正强制委派、旧工具 API 假定、凭 key 自动外部处理及固定失败比例停工要求，保留图完整性保护。
- `ui-ux-pro-max` 和仓库 `model-generation-evaluation` 缩短元数据描述，保留现有领域流程。

发布、推送、收费生成、对外发消息、旧工作区保护和具体平台拒绝仍保持原边界。当前请求不授权恢复之前被拒绝的 GUI 启动操作。
