## 1. 取消系统打印限色，保留单色写实

- 生成页不再展示打印色卡、颜色数量或耗材来源选择；生产路径的 `use_printable_colors()` 返回 false。保留“单色写实／多色写实／多色风格化”入口，单色写实仍要求单一材质外观及连续明暗。
- `openai_preprocessor.py` 的公开图片／文字预处理与设计图入口忽略旧 palette 参数。复用人物身份、构图、组件数量、服装覆盖和结构提示，移除打印颜色限制。单色指令仅在选择 sculpture 时附加。
- `model_job_support.py` 的三维提示不再注入打印 palette。Sidecar 的新建、旧推荐兼容入口、旧待确认任务继续、生成／恢复与重新贴色采用不限色策略；不重新提交已经记录的收费任务。已完成历史原件不改写，历史文件里已丢失的颜色不会凭空恢复。
- 保留原始 AI 设计图像素作为三维参考，不执行生成前减色；人像身份保护不再依赖耗材颜色数量。旧 palette 碎片门禁不阻止新策略的三维确认；参考图结构／清晰度等门禁仍保留。
- 新生成不创建旧的有限色目标清单，打印配色阶段需要针对当前模型建立新匹配。旧减色工具仍保留用于历史数据和离线专项测试，不由当前生成入口调用。
- 生成页三维预览改为顶点 RGB8 插值，不再归并为最多 64 个显示色组。OBJ 文件本身不因此重写。该着色器已随程序编译，但没有完成真实 GPU／主窗口视觉验证。

主要文件：`ModelGenerationPanel.cpp`、`ModelPreview3D.hpp`、`ModelColorPreviewShader.hpp`、`openai_preprocessor.py`、`model_job_support.py`、`orca_ai_sidecar.py`。

纹理转顶点颜色仍受网格采样分辨率影响；不限打印色数不等于与原始纹理逐像素一致。

## 2. 实际修改三维网格的本地处理

新增 `ModelFinishing.hpp/.cpp` 和 `ModelGenerationFinishingView.cpp`，由生成页调用，无需请求模型生成服务。

| 操作 | 实现与保护 |
|---|---|
| 表面美化 | 交替拉普拉斯平滑，默认强度 35%，可调；固定开放边、非流形边及锐边顶点，每点位移不超过原模型包围盒对角线 × 0.5% × 强度。检测面翻折／塌缩后拒绝保存。 |
| 网格修复 | 清理退化面和重复面，统一可定向连通面的方向，封闭部件朝外；统计开放边与非流形边。 |
| 比较 | 后台处理完成先产生未接受预览；同一相机、包围盒和灯光切换处理前／后，等待接受时禁止导入。 |
| 接受与撤回 | 接受后保存独立 OBJ 和 schema 4 来源记录；可返回上个版本，已接受派生版本仍保留在模型库。临时预览可放弃，后台计算可取消。 |
| 文件和颜色 | 不覆盖原件；保留顶点顺序、颜色尾字段、UV 和材质引用，几何修改后更新法向。派生文件与源文件同目录以保持相对材质路径。 |
| 追溯 | 记录源／结果 SHA-256、父模型、尺寸、参数、处理计数和可用参考图路径；提交文件前重新检查源文件哈希。 |
| 失效与恢复 | 接受后清空旧颜色意图／质量结论；本地版本的服务端复核入口禁用，提示导入准备页检查。切换模型使未接受预览失效；线程启动失败、取消、非法模型和写入失败保留原件。 |

当前支持三角 OBJ，最多 512 MB、200 万三角面、400 万顶点。错误处理和取消有自动验证；大模型实际耗时／内存尚未实机测量。

**能力边界：** 这是保守的表面美化与局部网格清理。没有实现语义化五官重塑、局部画笔、自动补洞、纹理接缝修复或自动消除异常色斑；不将开放边／非流形边的统计冒充这些问题已修复。薄壁、悬空、接地和制造适配仍要在准备页结合真实打印条件检查。
