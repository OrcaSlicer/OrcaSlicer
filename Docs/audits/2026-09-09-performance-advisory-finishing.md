## 改动

- 恢复已有作品时不重复请求风格推荐，避免取消模型下载。OBJ 解析和渲染数据准备移至后台；预览区域邻接和拾取 BVH 在实际选区操作时才计算。保留上一份预览的完整数据，缓存上限 384 MiB，按路径、大小和精确修改时间校验，供美颜前后对比。未降低原模型面数、颜色或导出精度。
- 最终外观复核改为用户主动触发，不再把五视图渲染和付费视觉评估放在生成完成的必经路径。交付完整性检查不再重复创建拓扑边表，详细结构报告仍计算并保留。
- 单色写实风格不变；多色写实和风格化沿用不限色设计与生成。图片尺寸/构图/连通性/空白、配色、身份、材料及结构检查均作提示，不因质量判定禁用生成或导入按钮。颜色清单不可用时使用 OBJ 自身颜色继续，绝不把不匹配清单附给导入器。损坏文件、不可解析索引、实际资源上限、任务状态和防止重复计费仍按执行有效性处理。
- 美颜新增轻柔、均衡、加强、仅修复四种选择和顶部直达入口；可调强度并重新预览。沿表面法线柔化，减少不规则网格上的切向漂移；每点位移同时受整体尺寸及局部边长约束，缓存面法线、跳过不变顶点重写。遇到局部翻折仅恢复涉及的点，其他区域继续处理。
- 美颜预览不进入正式模型库；接受后由元数据登记，保留材质相对路径。删除原记录时保护共享目录中的派生版本和图片。返回上个版本恢复路径、任务、配色、颜色意图和检查上下文；新一轮未接受预览不覆盖上一次已接受操作的撤销记录。加载失败保留当前模型和待接受预览。
- 结果滚动页在移动子窗口后刷新，清除 Windows 原生滚动复制出的 GL 残影；模型画布旁也提供前后对比，避免来回滚动。回退时同步恢复检查卡片，取消/保存时同步更新主状态。
- 退出崩溃的 DIA/PDB 调用栈为 `AIServiceManager::stop_owned_sidecar` → `Http::http_perform` → `form_file_read_cb` → `ifstream::tellg`。空 POST 未设置正文，误入文件读取回调。关闭本地服务时改发明确的 `{}` JSON 正文，接口、身份验证和端口不变；不修改通用 Http 或普通 Orca 流程。
