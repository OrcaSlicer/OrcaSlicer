# 六色耗材包与原生导入优化验收

本轮落实用户提供的年轻向六色包，并贯通美颜试色、Orca 原生颜色匹配和准备页。源码工作树修改尚未提交；验收使用隔离配置和既有模型，没有调用生成服务、隐式切片或改变日常配置。

## 最终行为

- 准备页“耗材色卡包…”与美颜“应用 / 保存耗材包…”共用色卡库。内置包按用户给定顺序对应六个实体槽；不足时补齐，其他槽位保留。
- 可命名保存当前前六个实体槽的颜色和原生多色外观元数据，下次快速选择应用。自动保存“上次应用前色卡”供恢复；应用是明确的工程级操作，影响使用这些槽位的所有模型，不表示打印机已经实际装料。
- 材料工艺预设、温度、流量不随色卡覆盖。自动冲刷量按 Orca 原设置刷新。模型 Undo 不管理耗材配置，因此耗材包通过重新应用旧卡恢复，而非承诺 Ctrl+Z 恢复槽位。
- 人物包先保留原模型关键颜色组，再用颜色特征为肤色、唇色、衣物及中性色分配目标色。修正首轮直接最近色匹配导致的粉色脸、黑衣领问题。普通自定义包继续近似匹配。
- 美颜色板传入原生匹配，原生窗口明确目标组数、实体耗材数和叠色数；调整耗材立即切换到耗材光照视图。全局颜色组替换与美颜局部编辑的影响范围有提示。
- 原生窗口复用面分组、只刷新改动组；固定色板避免无变化重算，计算中防止重复触发。叠色菜单改用标准按钮点击。
- 同一来源再导入可选择更新已有配色、新增并摆放或取消。更新前核对单部件的完整顶点和面索引，保留对象身份、位置、比例和其他配置；不兼容时说明原因并保留副本。
- 3MF 重开会丢失完整源路径；为生成器 UUID 文件名增加便携来源识别，更新仍需网格完全匹配。普通同名文件不会按这个规则合并。

## 实测结果

模型：原始人物 OBJ，约 98.2 MiB、1,906,896 三角面、39,863 原始色值、58.1 × 58.3 × 100 mm。

- 实际经过准备页保存旧四槽色卡 → 应用六色 → 历史加载 → 人物包纯色和光照预览 → 原生匹配 → 准备页 → 保存 3MF → 切回旧包 → 重开工程。
- 六色色号、槽位顺序完全符合用户输入。原生匹配确认 6 个目标组、6 个实体耗材、0 个叠色配方、0 个新增耗材。
- 保存工程含六种面涂色编码，计数分别为 275753、982390、84028、368644、182459、13622，总计 1,906,896 面。光照视图的亮暗不代表额外耗材。
- 旧四槽包切回后，面涂色 SHA256 同为 `8e7fc51335f46794755f9607e85b1732636e67f897cd38a8afd9fe61d79c9bd3`；模型变换及打印预设保持一致，仅对应槽颜色和自动冲刷矩阵改变。第 5、6 槽保留。
- 取消原生匹配后，保存的工程与取消前的面涂色、变换、六色、材料/打印机/工艺、温度、流量和冲刷矩阵一致；界面显示中性取消状态，无新增模型。
- 六色 3MF 可由普通 Orca 项目入口重开，未包含 G-code。
- 本机观测：历史加载界面显示 1.64–2.27 秒；人物包试色点击至截图约 0.64 秒；带模型切回旧卡约 1.30 秒。这些含自动化和截图开销，不是性能基准。原生首次匹配约 100 MB OBJ 仍需数十秒，不能称为即时导入。

## 已知边界

这是人物重新配色建议，并非语义分割；肤色/唇色/衣物分配仍依赖原模型颜色组。原始纹理中的领口黑色小斑块和底座边缘蓝色残留没有因此消失，应在已有美颜选区中局部改色/去杂色。此包没有绿色，绿色衣领会建议换蓝。

不新增重型依赖，至多六组枚举 720 种配色分配，复用 Oklab。未做实际打印、耗材光谱标定或 CMYK 叠色校准；屏幕光照只能辅助判断形体，不能保证实物色准。新增副本摆放及网格不兼容回退在代码中保留，实际覆盖范围须看后续验收记录。

## 重复更新及撤销验收

重新打开六色 3MF 后，历史载入同一原始 OBJ，再次导入已识别同源并显示选择。选择更新后，原生匹配将黑色组临时分配到灰棕槽；保存 `updated-existing.3mf`，随后 Ctrl+Z 并保存 `undo-update.3mf`。

三个工程的对象数均为 1、面数均为 1,906,896，位置变换完全一致。更新副本的黑色组与灰棕合并，灰棕计数为 644397；撤销副本的面涂色 SHA256 恢复为原工程值，六组计数一致。三个工程耗材色号、打印机/工艺/材料预设、温度、流量和冲刷矩阵完全一致。证据 `update-undo-evidence.json`。

最终本机 DLL SHA256：`36D94D38D177D34B3ADE2972523F4A01C57D2EE2B5C48E392FD430F1E2FDB1B1`。构建日志 `.tmp/color-pack-button-build.log`；新增来源判断构建 `.tmp/color-pack-reopen-build-2.log`。最终复制至 `build/color-pack-preview`。

手动映射提示和保持已有对象的更新已实测；新增副本自动摆放及不兼容回退未进行完整 GUI 验收，不能据此承诺所有复杂工程都已覆盖。
