# Fields `set_feature_expr` can bind

Generated by `scripts/CAD/gen_bindable_fields.py` from a running app (the kernel's allow-list, `CadDocument::bindable_fields`). Do not edit by hand.

`set_feature_expr {feature, field, expr}` binds one field to an expression over the variables. A field not in this list is refused with `unknown parameter: <field>` and the document is left unchanged.
