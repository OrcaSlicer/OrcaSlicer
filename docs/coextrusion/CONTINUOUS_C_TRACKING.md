# 连续曲面 C 轴跟随停顿修正

2026-09-07：`aaasss.gcode` 确认使用 `normal_xy` 二维模型，但大角度策略仍为 `preposition`。文件中有 3837 条 C 单独运动指令，其中 3623 次角度差大于零且不超过 15°，63 次超过 180°。这些统计包含起始定位和空移定位，不全部属于曲面跟随。

典型外墙指令反复出现回抽、C 单独调整 4°～6°、恢复挤出、XY 挤出。根因是规划器采用保守的从静止加速再减速到静止的转动时间，短线段的名义时间不足时，旧 `preposition` 配置将微小调整也变成独立定位。二维、三维共用该运动规划器，因此切换几何公式不能解决它。

修正：相邻、端点连接、方向已解析、目标颜色一致且实际 C 角差不超过 45°的调整，优先使用 `SlowDownRequired` 同步降速，不受大角度回退策略影响。45°沿用已有过渡规划的不连续角阈值。换色、首段定位、超过 180°的有限轴退绕仍由原分支处理。默认大角度策略改为 `slow_down`，已保存的旧策略仍可读取。

本次保留保守加减速时间估计，因此仍可能降低打印速度；未实现跨段连续角速度前瞻，不能据此保证机械运动完全匀速。

手动验证（未编译、未执行测试）：

- 使用原模型、二维模式和旧 `preposition` 配置重新切片，同色曲面的小角度调整应输出带 C 的 XY 挤出运动，必要时降低 F，不再逐段回抽和单独转 C。
- 三维模式重新切片，确认同样适用；换色及需要退绕的地方仍应停止显色挤出再定位。
- 保存并重新打开工艺，确认策略值保持；新默认使用 `slow_down`。
- `aaasss.gcode` 实际仍记录 C 范围 ±360°、转速上限 360°/秒。实机要求为 ±180°、90°/秒，重新切片前应修正当前项目的机器配置及覆盖值；本补丁没有把通用规划器的可配置范围硬编码为特定机器参数。
