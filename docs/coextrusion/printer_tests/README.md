# 第一轮实物验证 G-code

## 当前文件状态

已按用户确认的机器信息生成四个完整 `.gcode`：110×110 mm、喷嘴 0.4 mm、耗材 1.75 mm、喷嘴 200°C、热床 55°C、Marlin、C 轴手动归零、限位 [−360°,360°]、角速度 90°/s。`G1 Y+` 时平台靠近观察者。

`.gcode.in` 是带占位符的源模板，不能直接运行。实际使用下表中的 `.gcode`。[生成脚本](../../../scripts/generate_coextrusion_printer_tests.py)只写文件，不连接打印机，也不编译切片器。本次生成命令为：

```powershell
python scripts/generate_coextrusion_printer_tests.py --c-min -360 --c-max 360 --protocol-confirmed
```

已检查生成文件的占位符和指令坐标范围，没有进行固件执行或实物验证。自定义 Marlin 应已将 C 配置为以度为单位的旋转轴；固件名称本身不能替代这个设置。

本轮采用层高 0.2 mm、线宽 0.45 mm、打印速度 15 mm/s、空移 30 mm/s、回抽 0.6 mm（20 mm/s）。直线区域 X=25～73、Y=35～65；方墙 X=25～45、Y=35～55，高 4 mm。排料采用用户提供的 `ssr.gcode` 床边双线：X=0/0.4、Y=10～90、Z=0.28。结束停在 X=15、Y=95、Z=8。

01～03 的启动段已参考共享目录中的 `ssr.gcode` 更新：运动参数与速度/流量倍率初始化 → 热床 55°C、喷嘴预热 150°C → 等待热床 → G28 回零 → G29 调平 → 记录 C 零位 → 喷嘴升至并等待 200°C → 床边双线排料 → 回抽 0.6 mm → M83 相对挤出 → 测试路径。保留参考文件的加速度设置，C 最大角速度改为本轮指定的 90°/s。

01～03 已自动完成 XYZ 回零和调平；运行前仍须清空底板并手动对准真实 C=0。00 是独立的冷态旋转测试，不加热、不执行 G28/G29，需事先让喷嘴避开床面和物件。文件仅用一次 G92 C0 记录已建立的物理零位，打印过程中不做周期归一化。G92 不会替你解扭。

C=0 应对应无误的初始颜色分布：红中心 X+，蓝中心物理顺时针 120°，绿中心 240°。若手动转动需暂时失能电机，应使用机器现有操作方式；本文件不自动释放 Z 或其他轴。

这些路径用于直接检验物理理论，绕过切片器的法线匹配、角度容差、延迟补偿和连续旋转规划。没有编译或执行打印机运动。

## 测试顺序与预期

| 文件 | 内容 | 观察重点 |
|---|---|---|
| [00_c_direction.gcode](00_c_direction.gcode) | C=0→30→0→−30→0，分步停留，无加热/挤出 | 俯视正值顺时针、负值逆时针，返回机械零位是否一致 |
| [01_fixed_c_four_directions.gcode](01_fixed_c_four_directions.gcode) | 固定 C=15°，打印四条相互分离的 30 mm 直线 | 按 G-code 指令方向：+X 蓝、−X 红、+Y 蓝、−Y 绿 |
| [02_blue_top_four_directions.gcode](02_blue_top_four_directions.gcode) | 同样四条线，分别使用 C=60/−120/−30/150° | 四条线的顶部中心应都对应蓝色中心 |
| [03_blue_square_wall.gcode](03_blue_square_wall.gcode) | 20×20×4 mm 方墙，20 层 | 从四个外侧分别沿外法线观察，四面应都偏蓝色；不要求顶部也为蓝色 |

前三项通过后再做方墙。斜面、真正 XYZ 倾斜挤出、同步旋转和响应延迟留给第二轮，以免多个未知因素混在一起。不能直接在空中打印一条上坡线来代表受支撑的斜面显色。

“预期颜色”指理想模型中对应观察方向的局部颜色，不表示整条可见截面只会出现一种颜色。单层线会被压扁，底板和相邻侧面的颜色也可能进入视野。

固定 C 测试选择 15° 是为了避免四个观察方向正好落在理想色区边界，但按本机指令方向 +X/+Y 两条距边界只有 15°，它们更容易暴露安装偏移。蓝色中心对准测试可进一步区分零偏和方向映射问题。

## 本机器必须应用的 Y 方向转换

用户确认平台在 `G1 Y+` 时靠近观察者。在此前定义的物理坐标中，这对应平台 +Y 运动，喷嘴相对模型则是 −Y 运动。因此用于公式的物理向量应为：

\[
v_{physical}=(v_{command,x},-v_{command,y},v_{command,z})
\]

与指令轨迹一起定义的形状外法线也需要同样反射 Y，不能只转换运动方向。对顶面 n=(0,0,1)，法线不变，只有水平运动方向发生改变。

所以 `G1 Y+` 的蓝色顶面使用 C=−30°，`G1 Y−` 使用 C=150°。这是坐标转换，不是改变几何公式或把 C 正方向改成逆时针。方墙指令 Y 最小边对应物理 +Y 外法线，指令 Y 最大边对应物理 −Y 外法线。

这些手写测试已按此转换生成。此前切片器求解入口直接使用网格和路径分量，并没有新增此机器专用反射选项；将本测试结果推广回自动切片时，还需要在切片坐标到物理坐标的接口统一处理这一对应关系。

## 参数和固件约定

执行前使用机器现有配置确认：

- 实际可用 X/Y/Z 范围、测试区域位置、喷嘴直径、耗材直径。
- 机器可以正常打印本轮指定的温度，层高 0.2、线宽 0.45、回抽 0.6 mm 适用。
- Marlin 已启用自定义 C 旋转轴，G90 下 C 使用绝对度，G92 C0 可设置该轴坐标。
- 挤出量按耗材长度毫米解释（不是体积模式）；速度/流量倍率按 100% 使用。
- C 手动零位没有把上一轮的线缆扭转误记为新的零位。

生成脚本使用的通用指令语义参考 Marlin 官方 [G0/G1](https://marlinfw.org/docs/gcode/G000-G001.html)、[G92](https://marlinfw.org/docs/gcode/G092.html)、[M83](https://marlinfw.org/docs/gcode/M083.html)。这些文档不证明用户自定义固件已经支持相同的旋转轴行为。

模板约定 XYZ 使用绝对毫米，E 使用相对耗材长度毫米，C 使用绝对度，C 单独运动的 F 使用度/分钟；其余 F 使用毫米/分钟。不使用 G92 C，不把大角差自动改写为模 360 的短转角。正式文件须按固件能力调整这些约定。

00 使用 [−30°,30°]。其他打印文件使用 [−120°,150°] 内的 C 目标，均位于已确认的 [−360°,360°] 内。方墙的 −120→150 是真实的 +270°，不是 −90°；模板有意保持固定绝对目标，且旋转前回抽抬高。这一轮不做最短旋转效率比较。

`START_PRINT_GCODE` 完成 XYZ 回零、调平、加热、记录手动建立的 C 零位及床边排料；排料使用 M82 绝对 E（15、30 mm），随后回抽 0.6 mm 并切换 M83。测试主体假定启动块结束时已有 0.6 mm 回抽，第一条线开始前恰好恢复 0.6 mm，不会重复回抽或多恢复。

打印结束时模板保持回抽状态，并抬至对应安全高度。`END_PRINT_GCODE` 要适配此状态，不应在仍接触试件时突然旋转 C。未确认前不添加通用 G28、关闭所有电机或臆测的 C 归零命令。

## 挤出量与层高

`E_LINE_30MM`、`E_LINE_20MM` 由确认后的耗材直径 d、层高 h、线宽 w 和流量倍率 f 计算。可先沿用切片器的圆角矩形近似（w≥h）：

\[
A=h(w-h)+\pi h^2/4,\qquad E=L A f/(\pi d^2/4)
\]

第一层压扁程度可能需要单独流量修正。启动排料不算在观察区，先看线条后半段，避免将启动欠挤或材料初始响应误当作角度错误。

方墙按层重复 03：首次挤出高度使用第一层 Z，之后按层高递增。每次旋转前的 `LAYER_TRAVEL_Z` 必须高于已打印的整面墙，不应固定为第一层的抬升高度。层间总高度、打印速度和冷却按实际材料设置。

- 00 不符合：先解决 C 方向/零位，后续显色结果暂不可用。
- 01 随方向变化基本符合、02 全部偏同一种其他颜色：优先检查颜色区实际顺序和安装偏移。
- X 向正常、Y 向系统性相反：检查相对运动与平台运动的坐标关系，不直接给所有 C 加负号。
- 线条后半段正确而开始错误：记录过渡长度，再安排响应延迟测试。
- 顶面与侧面不能用同一校准同时匹配：记录层高与流量，进一步判断沉积截面变形或理想弯折模型的局限。
