# 颜色交界接缝与起始 C 轴定位

原接缝策略通过接缝绘制、可见性、悬垂和对齐／背面／就近等设置选择位置，没有把表面颜色变化作为候选。原 C 轴定位在空移到起点并恢复挤出后执行，会在接缝处再次回抽、旋转、恢复挤出。

启用 C 轴和表面颜色控制后，内外墙改为：

1. 从同一体积中不同颜色切片线段的公共端点提取交界。
2. 将交界投影到外墙挤出中心线，排除距离过远、属于其他轮廓或被接缝绘制禁止的位置。若原接缝是手动强制点，则保留手动选择。
3. 在剩余交界中选择离原策略接缝最近的位置；内外墙使用所属外轮廓作为共同的候选筛选、距离排序依据，再将选中的交界投影到各自墙线。选中交界的内墙不再应用原凹角偏移和内墙接缝错位，避免重新偏离交界。没有可用交界及螺旋模式保持原策略。
4. 颜色交界接缝不使用斜接缝，避免重叠渐变段跨越两种颜色。表面控制启用时跳过外墙起点前的擦拭预挤出，使真实路径负责恢复挤出。

C 轴规划提前到路径空移之前，继续使用原路径组规划及延迟补偿结果。当首段需要初始化、预定位或限位退绕时，输出顺序为：

**回抽／擦拭 → 按配置抬 Z → C 轴定位 → 空移到路径起点 → 恢复 Z 和挤出 → XY/E/C 打印。**

定位使用起点之后第一段的目标角度，完成后消费首段定位状态，避免重复回抽旋转。C 轴保持物理绝对坐标，沿用 ±180° 限位。此次定位在空移出发处独立完成，尚未将 C 旋转与 XY 空移合并为一条运动指令。Z 抬升高度来自现有回抽抬升配置。

这里的交界是模型涂色的交界；单色表面的法线变化和 C 角度跨越 ±180° 不会生成新的颜色交界候选。一圈中的其他颜色变化或必须退绕的位置仍由原 C 轴规划处理。

## 手动验证（本次未执行编译或测试）

- 给圆柱侧面涂两个竖向色块：外墙接缝应落在色块交界附近的挤出中心线上。
- 将一处交界绘制为禁止接缝，或在其他位置绘制强制接缝：确认手动约束生效。
- 对双色圆柱使用先内后外顺序：内外墙起止点应投影到同一交界附近，不应额外在 X+ 方向留下内墙接缝；分别检查启用和关闭内墙接缝错位的情况。
- 对单色圆柱和关闭表面控制的项目重新切片：确认继续使用原接缝策略。
- 检查 G-code 中 `co-extrusion C-axis preposition before travel`：应位于到起点的空移和恢复挤出之前，第一段不应再重复独立 C 定位。
- 使用需要从接近 +180° 返回负角度的路径：返回过程应在非挤出阶段完成，C 指令仍在机器配置限位内。
